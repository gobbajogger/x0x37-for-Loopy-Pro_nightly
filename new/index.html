Release status

Updated 13 November 2026. This page describes the NIGHTLY channel, not a production release.

0.0.26 — withdrawn

Removed from the installer after reports of updates stuck at Restarting and very long or failed startup. A corrected package has not been published. Do not reinstall a saved 0.0.26 package as a recovery step.

Artifacts and development history are retained for investigation; retained files are not an installation recommendation.

Withdrawal record

0.0.25.1 — available development package

The latest selectable package is 0.0.25.1. Its on-device version label is 0.0.25. Model-specific packages, exact source and verification details are available in the installer. A successful recovery on one device is not proof of validation for every model.

Open installer · Browse retained build history

Installer restart handling

The installer now handles repeated final loader acknowledgements and bounds reconnect attempts. These changes do not establish the cause of the firmware startup failure.
