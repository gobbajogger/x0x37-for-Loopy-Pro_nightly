SMK-37 guide

Installation, backups and troubleshooting for DnBOX on SMK-37 Pro and Elite.

0.0.26 is a development test build. An earlier 0.0.26 candidate (600b3b45) was withdrawn. The current 0.0.26 (94197fc8) replaces it. The project owner reported testing 0.0.25.1 and 0.0.26 on an SMK-37 Elite. The Pro has not been tested on a device yet. This is not a full hardware qualification of either model. The installer offers 0.0.26, 0.0.25.1 and earlier development packages.

Install and keep a backup

  1. Open the installer. Choose the model printed on your keyboard; the installer also checks the connected device.
  2. Before changing firmware, save important samples with Samples and export songs with Songs & projects. Keep the exported files.
  3. Review the selected package and development warning. Keep USB connected throughout writing, verification and restart.

Package 0.0.25.1 displays firmware version 0.0.25 on the device. The package revision distinguishes the update; it is not a different keyboard model.

Connection and recovery

Use the installer’s Connection & recovery help for its supported browser and connection paths, including mobile guidance where available. A connection name is not proof of the board model.

If an update stays at Restarting or the screen remains black, retain the activity log, selected package version and exact model. Report them in SMK startup and recovery support. Do not use another device’s stock firmware or recovery instructions.

Using the firmware

The full playing manual is being reconciled with the current SMK build. Until that is complete, older X0X documentation may describe a different device or control layout. Do not treat its FM-1 recovery procedure as an SMK procedure.
