Device operations require a USB data cable, HTTPS (or localhost), and Web MIDI with SysEx permission. Use desktop Chrome or Edge. Safari and iOS browsers do not provide the required Web MIDI access. You can still browse this page without a device.

If the sample panel does not load, open the standalone sample tools. Prepared changes remain in the current panel while it stays open.

Firmware installation changes the device software. SMK-37 Elite and Pro need their matching package; FM-1 support depends on the selected package. A supported model alone does not mean an installable build exists. DEV / HARDWARE TEST means DEVICE NOT TESTED.
